# 隐私与数据流

- 麦克风、文字及按请求截取的主屏幕图像发往阿里云。不是持续共享，正常截图不落盘；云端保留由账户和提供方政策决定。
- GPU 开启时回复音频发往服务，通话音频和帧在有界内存中，合成待机动画落盘。
- 任务目标和必要上下文发往 dsh，由其模型、工具和历史配置决定执行。取消不撤销已执行操作。
- Soul 任务表属于通话，挂断及正常退出取消未完成任务。强制退出无法保证取消，须在 dsh 核对。
- 凭据仅主进程使用，云端和 dsh 配置用 Windows DPAPI。偏好为普通 JSON。诊断含状态与 ID，不含音频或正文。
- Langfuse 默认关闭；启用保存文字、参数、结果、目标、标识和耗时，截图仅元数据。不能保证脱敏自由文本中的所有秘密。
- 测试可能产生截图、日志、报告、云端记忆与会话，使用隔离账户，不上传缓存或用户数据。

GPU 仅 loopback，经 SSH 隧道访问，无公网鉴权和配额保护，不直接公开端口。dsh 仅本机连接。
